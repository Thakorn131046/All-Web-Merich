## ✨ ฟีเจอร์เด่นของเว็บพอร์ทัล

- ⭐ **ปักหมุดระบบโปรด (Favorites):** คลิกไอคอนดาวเพื่อนำระบบที่ใช้งานบ่อยมาแสดงไว้ที่ส่วนบนสุด (บันทึกอัตโนมัติในเครื่อง)
- 🔍 **ระบบค้นหาอัจฉริยะ (Smart Search):** ค้นหาได้ทั้งชื่อระบบภาษาไทย, ภาษาอังกฤษ, ตัวย่อ (RP, AR, TS, QC, WH), หมวดหมู่ หรือ URL ได้ทันที
- 🗂️ **แท็บหมวดหมู่พร้อมจำนวนนับ:** แยกตามฝ่าย IT & แจ้งซ่อม, ฝ่ายขาย & วางแผน, คลังสินค้า & QC, และบัญชี & การเงิน
- 📋 **คัดลอกลิงก์ด้วยคลิกเดียว (Copy to Clipboard):** ส่งต่อลิงก์ระบบงานให้เพื่อนร่วมงานได้สะดวกรวดเร็ว
- 🔲 **สลับมุมมอง (Grid / List View):** เลือกระหว่างมุมมองการ์ดกราฟิกสวยงาม หรือมุมมองตารางกะทัดรัด
- ⏱️ **นาฬิกาและวันที่แบบเรียลไทม์:** แสดงเวลาและวันที่ภาษาไทยแบบสด
- 📱 **รองรับทุกหน้าจอ (Fully Responsive):** ใช้งานได้สมบูรณ์แบบทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน

## 🚀 การติดตั้งและ Deploy (GitHub Pages)

โปรเจกต์นี้ตั้งค่า **GitHub Actions** (`.github/workflows/deploy.yml`) เพื่อ Deploy เว็บไซต์ขึ้นสู่ **GitHub Pages** อัตโนมัติทุกครั้งที่มีการ Push โค้ดขึ้นสู่ Branch `main`

### วิธีเปิดใช้งาน GitHub Pages ครั้งแรก:
1. เข้าไปที่เมนู **Settings** ของ Repository บน GitHub
2. ไปที่หัวข้อ **Pages** (เมนูด้านซ้าย)
3. ใต้หัวข้อ **Build and deployment > Source**:
   - เลือก **GitHub Actions** (ระบบจะรัน Workflow อัตโนมัติ)
   - หรือเลือก **Deploy from a branch** โดยเลือก Branch เป็น `main` และโฟลเดอร์เป็น `/ (root)` แล้วกด **Save**
4. เว็บไซต์จะพร้อมใช้งานทันทีที่: `https://thakorn131046.github.io/All-Web-Merich/`
